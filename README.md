# Fiqh-Quiz-Game

### Introducing the Program:
*Fiqh Quiz Game* is a Quiz game that tests your knowledge in the Islamic science called 'Fiqh'(Islamic jurisprudence).


### What it does?:
1. It gives user choice between three levels of difficulty(for questions), which are **Easy, Medium and Hard**.
2. Based on user's choice, the program will display five questions one-by-one and will give opportunity for user to answer them.
3. The program will track the score(0-5) based on user's answers.

### What was used to make this program?:
Software: VSCodium

C++ Standard: C++17

Compiler: g++

Primarily, functions, arrays, loops, and conditionals(if-else) were used.
